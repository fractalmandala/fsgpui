# AGENTS.md

This is a gpuix-fractalsvelte app: Svelte 5 components rendered
into a native desktop window by GPUI, the GPU-accelerated UI framework behind the Zed editor. It runs
on Node.js >= 24 or Bun >= 1.4.

Please cascade up to mother folder `fsgpui` and read the `AGENTS.md` there - `fsgpui/AGENTS.md`
